# AI 프롬프트 작성 가이드

> 바이브 코딩에서 AI를 효과적으로 활용하기 위한 프롬프트 패턴 모음

---

## 황금 원칙

1. **컨텍스트를 충분히 줘라** — "버튼 만들어줘" ❌ → "로그인 폼 하단에 들어갈 제출 버튼, primary 스타일, 로딩 상태 포함" ✅
2. **기술 스택을 명시해라** — "React + TypeScript + Tailwind CSS 사용 중"
3. **결과물 형식을 지정해라** — "컴포넌트 파일 하나로, Props 타입 포함해서"
4. **제약 조건을 알려줘라** — "서버 없이 클라이언트만, 로컬스토리지 사용"

---

## 프롬프트 템플릿

### 1. 컴포넌트 생성

```
[기술 스택]: React + TypeScript + Tailwind CSS

[요구사항]:
- [컴포넌트 이름]: [컴포넌트 역할 설명]
- Props: [필요한 Props 나열]
- 상태: [필요한 상태 나열]
- 스타일: [디자인 요구사항]

[제약 조건]:
- [있다면 작성]

컴포넌트 파일 하나로 만들어주고 Props 타입도 포함해줘.
```

### 2. 기능 구현

```
[컨텍스트]:
현재 [파일명]에서 작업 중이고, [현재 상태 설명].

[할 일]:
[기능명] 기능을 구현해줘.
- [세부 요구사항 1]
- [세부 요구사항 2]
- [세부 요구사항 3]

[주의사항]:
- TypeScript 타입 엄격하게
- [추가 주의사항]
```

### 3. 버그 수정

```
[문제]:
[에러 메시지 또는 증상]

[코드]:
[문제가 있는 코드 붙여넣기]

[예상 동작 vs 실제 동작]:
- 기대: [기대하는 동작]
- 실제: [실제 동작]

원인 파악하고 수정해줘.
```

### 4. 리팩토링

```
아래 코드를 리팩토링해줘.

[코드 붙여넣기]

목표:
- [가독성 개선 / 중복 제거 / 성능 개선 등]
- 기존 동작은 유지
- 타입 안전성 유지
```

### 5. 페이지 레이아웃

```
[페이지명] 페이지 레이아웃을 만들어줘.

디자인 요구사항:
- 반응형: [모바일 / 데스크톱 / 둘 다]
- 레이아웃: [헤더 + 사이드바 + 컨텐츠 / 그리드 등]
- 컬러: [사용할 컬러]

포함할 섹션:
1. [섹션 1]
2. [섹션 2]

Tailwind CSS 사용, 목업 데이터로 채워줘.
```

## 고급 프롬프트 패턴

### 단계별 개발 (복잡한 기능)

```
[기능명]을 단계별로 만들어줘.

1단계: 타입/인터페이스 정의만
2단계: 1단계 타입 기반으로 상태 관리 로직
3단계: 2단계 로직 기반으로 UI 컴포넌트

지금은 1단계만 해줘.
```

### 빠른 목업 만들기

```
[화면 설명]을 빠르게 목업으로 만들어줘.

- 실제 데이터 연결 없이 하드코딩된 목업 데이터 사용
- 스타일은 Tailwind, 깔끔하게
- 동작하는 것처럼 보이면 됨 (실제 기능 불필요)
- 파일 하나로
```

### 에러 핸들링 추가

```
아래 코드에 에러 핸들링을 추가해줘.

[코드]

- 로딩 상태 처리
- 에러 상태 처리  
- 빈 데이터 상태 처리
각 상태에 맞는 UI도 포함
```

### API 연동

```
아래 API 스펙으로 fetch 함수를 만들어줘.

엔드포인트: [URL]
메서드: [GET/POST/PUT/DELETE]
요청 바디: [있다면 작성]
응답: [응답 타입]

- TypeScript 타입 정의 포함
- 에러 처리 포함
- async/await 사용
```

## 자주 쓰는 프롬프트 스니펫

### 프로젝트 컨텍스트 시작 문구

Claude Code를 열면 먼저 이 문구로 시작:
```
지금 우아한 테크코스 해커톤 진행 중이야.
프로젝트는 [프로젝트 설명].
내 담당 기능은 [담당 기능]이야.
React + TypeScript + Tailwind CSS 사용 중이고,
workspace/[내 닉네임]/ 폴더에서 작업 중이야.
```

### 빠른 수정 요청

```
이 코드에서 [문제점]만 고쳐줘. 다른 건 건드리지 말고.
```

### 스타일 조정

```
이 컴포넌트 스타일만 수정해줘.
- 더 [모던하게 / 깔끔하게 / 심플하게]
- 컬러는 [기존 유지 / [색상]으로]
- 로직은 건드리지 말고 className만
```
