# 09. 디자인 명세서

> **컨셉**: 포켓몬스터 마을(탑다운 픽셀 아트 맵) + 동물의 숲(따뜻한 자연 색감, 아기자기한 캐릭터)의 융합  
> **핵심 감성**: 아늑하고 따뜻한 우테코 캠프 분위기. "같이 공부하는 아지트"

---

## 1. 비주얼 레퍼런스 정리

### 포켓몬스터에서 차용
- **탑다운 2D 시점** — 45° 없음, 정직한 top-down
- **타일 기반 맵** — 16×16 또는 32×32px 픽셀 타일
- **NPC 대화 박스** — 아래쪽 고정 말풍선 UI
- **장소 이름 전환 오버레이** — 층 이동 시 검정 페이드 + 마을명 텍스트

### 동물의 숲에서 차용
- **따뜻한 자연 팔레트** — 그린, 베이지, 하늘색, 나무 질감
- **둥글둥글한 캐릭터** — 큰 머리, 작은 몸통 비율
- **아이템·가구 배치 느낌** — 소품이 귀엽게 배치된 공간감
- **계절/시간 분위기** — 낮/밤 색조 변화 (선택 사항)

## 3. 타일 디자인

### 타일 크기: 16×16px (렌더링 시 ×2 스케일 → 화면에서 32×32px)

픽셀 아트 작업 시 16×16 기준으로 그리고, CSS/Canvas `imageRendering: pixelated`로 확대

### 타일 종류별 디자인 가이드

#### 바닥 타일

| 타일 | 디자인 설명 | 색상 |
|------|-------------|------|
| 잔디 (기본) | 밝은 초록 바닥에 랜덤 3~4종 잡초 점 | `#A8C78A` + `#7EA85F` 변형 |
| 흙길 | 베이지 타일, 약간의 모래알 노이즈 텍스처 | `#D4B896` |
| 나무 바닥 | 갈색 나뭇결, 좌→우 방향 | `#C19A6B` |
| 장식 가능 구역 | 연한 풀밭, 점선 테두리 표시 | `#B5D99C` |

#### 벽 타일

| 타일 | 디자인 설명 |
|------|-------------|
| 돌담 | 밝은 회색 + 어두운 돌 경계선, 이끼 점 |
| 나무 울타리 | 갈색 수직 나무 기둥 + 수평 가로대 |
| 꽃담 | 흰 돌담 위에 꽃 장식 |

#### 기물 타일

| 기물 | 픽셀 아트 방향 |
|------|----------------|
| 🪣 우물가 | 회색 돌 기단 + 나무 지붕 + 두레박. 포켓몬 우물 스타일 |
| 📋 게시판 | 나무 기둥 + 코르크 보드 + 흰 종이 몇 장 핀으로 고정 |
| 🪜 계단 | 밝은 돌 계단, 위층으로 빨려들어가는 느낌. 화살표 없이 3단 계단 |
| 🏠 마을 입구 | 나무 아치문, 위에 마을 이름 현판 |

## 4. 캐릭터 디자인

### 기본 캐릭터 비율 (16×24px)

```
  [●●●]     ← 머리: 10×10px, 크고 둥근 형태 (동물의 숲 비율)
  [몸통]     ← 몸통: 8×8px
  [다리]     ← 다리: 4×6px, 걸을 때 앞뒤 교대
```

### 방향별 스프라이트 (4방향)

| 방향 | 스프라이트 수 | 설명 |
|------|---------------|------|
| 아래 (기본) | 3장 | 정면, 왼발, 오른발 |
| 위 | 3장 | 뒷모습 |
| 왼쪽 | 3장 | 측면 |
| 오른쪽 | 3장 | 측면 (좌우 반전으로 대체 가능) |

→ 총 12장 (1 스프라이트 시트)

### 분야별 기본 캐릭터 컬러

| 분야 | 상의 색 | 특징 |
|------|---------|------|
| Android (AN) | 초록 `#4CAF50` | 안드로이드 안테나 머리 장식 |
| Frontend (FE) | 파랑 `#42A5F5` | 작은 모니터 배지 |
| Backend (BE) | 주황 `#FF8F00` | 커피컵 들고 있음 |
| Coach | 보라 `#9C27B0` | 안경 + 별 장식 |

### 코스튬 시스템 (우마 구매)

```
레이어 구조 (아래→위):
  1. 몸통 색 (기본)
  2. 상의 아이템 (모자, 안경)
  3. 들고 있는 아이템 (지팡이, 커피컵, 책)
  4. 말풍선 / 이모지
```

### 이름 말풍선

```
┌─ mychan ─┐
│           │  ← 흰 배경, 둥근 모서리 8px, 그림자
└─────────┘
     ▼        ← 캐릭터 머리 위 작은 삼각 꼬리
```

- 폰트: 고딕 계열, 11px, bold
- 배경: `#FFFFFFEE`
- 테두리: `#C8B89A` (따뜻한 베이지 톤)

## 5. UI 디자인 시스템

### 5-1. 전체 UI 컨셉: "우테코 공지판 스타일"

```
- 배경: 크림 베이지 (#FFF8E7)
- 카드: 흰색 + 연한 나무 테두리
- 버튼: 둥글고 따뜻한 색감
- 아이콘: 픽셀 아트 스타일 이모지 사용
```

### 5-2. 타이포그래피

| 용도 | 폰트 | 크기 | 굵기 |
|------|------|------|------|
| 게임 타이틀 | DotGothic16 (구글폰트) | 28px | — |
| 마을 이름 / 층 배지 | DotGothic16 | 16px | — |
| 대화 박스 텍스트 | Noto Sans KR | 14px | 400 |
| 게시판 제목 | Noto Sans KR | 15px | 700 |
| 게시판 본문 | Noto Sans KR | 13px | 400 |
| HUD / 우마 잔액 | DotGothic16 | 13px | — |
| 입력창 | Noto Sans KR | 14px | 400 |

> **DotGothic16**: 픽셀 느낌 한국어 폰트. 맵 내 텍스트에 사용.  
> **Noto Sans KR**: 게시판·모달 등 일반 UI에 사용.

```html
<!-- Google Fonts 로드 -->
<link href="https://fonts.googleapis.com/css2?family=DotGothic16&family=Noto+Sans+KR:wght@400;700&display=swap" rel="stylesheet">
```

### 5-3. 버튼 스타일

#### Primary 버튼
```css
background: #4CAF50;        /* 마을 테마색 적용 가능 */
color: #ffffff;
border: 2px solid #2E7D32;
border-radius: 8px;
padding: 8px 20px;
font-family: 'DotGothic16';
font-size: 14px;
box-shadow: 0 3px 0 #2E7D32;  /* 포켓몬 버튼 특유의 아래 그림자 */
cursor: pointer;

/* 클릭 시 */
transform: translateY(2px);
box-shadow: 0 1px 0 #2E7D32;
```

#### Secondary 버튼
```css
background: #FFF8E7;
color: #2D1B0E;
border: 2px solid #C8B89A;
border-radius: 8px;
box-shadow: 0 3px 0 #C8B89A;
```

### 5-4. 모달 / 대화 박스

#### 포켓몬 스타일 대화 박스 (기물 상호작용 시)

```
┌─────────────────────────────────────────────────┐
│                                                  │
│   게시판에는 여러 질문이 가득해요!                 │  ← 14px, Noto Sans KR
│   [E] 게시판 열기  [ESC] 닫기                    │
│                                                  │
└─────────────────────────────────────────────────┘

디자인:
- 화면 하단 고정 (bottom: 16px)
- 배경: #FFF8E7, 테두리: 3px solid #5C3D2E
- 모서리: 8px
- 좌우 패딩: 20px
- 삼각형 포인터 없음 (게임 박스 스타일)
- 우측에 ▼ 깜빡임 (텍스트 계속 있음 표시)
```

#### 게시판 / 마이페이지 모달 (일반 UI)

```
┌──────────────────────────────────────────────┐
│ 📋 게시판              [11F 구리마을]    [✕] │  ← 헤더
├──────────────────────────────────────────────┤
│ [전체] [구리마을] [태초마을] [뽀롱뽀롱]       │  ← 탭
├──────────────────────────────────────────────┤
│                                              │
│  [ 글 목록 영역 ]                            │
│                                              │
└──────────────────────────────────────────────┘

디자인:
- 배경: #FFF8E7
- 헤더 배경: 마을 테마색 (연하게 20% opacity)
- 탭: 선택 시 테마색 밑줄 + bold
- 카드: 흰 배경 + `box-shadow: 0 2px 6px #0001`
- 모서리: 12px
```

## 6. 맵 전체 레이아웃 디자인

### 층 이동 전환 효과 (포켓몬 마을 진입 스타일)

```
1. 화면 검정 페이드 아웃 (0.3s)
2. 검정 화면 중앙에 흰 텍스트로 층 이름 등장
   → "12F 태초마을에 오신 걸 환영합니다!"  (DotGothic16, 18px)
3. 텍스트 1초 유지
4. 페이드 인 (0.3s)
```

## 8. 애니메이션 가이드

| 대상 | 애니메이션 | 스펙 |
|------|------------|------|
| 캐릭터 이동 | 4프레임 걷기 | 100ms/프레임 |
| 캐릭터 정지 | 2프레임 숨쉬기 | 500ms/프레임 |
| 우물 물결 | 2프레임 반짝 | 800ms |
| 게시판 종이 | 바람에 살짝 흔들 | 1.2s ease-in-out loop |
| 계단 발광 | 펄스 (opacity 0.5↔1) | 600ms loop |
| 층 전환 | 검정 페이드 아웃/인 | 300ms |
| 이모지 플로팅 | 위로 떠서 사라짐 | 2000ms |
| 우마 획득 알림 | 위로 튀어오름 +bounce | 1000ms |
| 버튼 클릭 | translateY(2px) | 100ms |
